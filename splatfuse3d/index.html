Abstract

SplatFuse3D studies geometry-verified segmentation in 3D Gaussian representations, targeting robust extraction of whole objects and fine-grained parts. This page intentionally uses maintainers-editable placeholders for figures, metrics, and media until curated assets are ready for publication.

Key Contributions & Method Overview

Geometry Verification

Integrates geometric consistency checks to filter ambiguous segmentation assignments in sparse and dense scene regions.

Object + Part Extraction

Supports both full object masks and part-level extraction for downstream analysis and compositional scene editing tasks.

Reproducible Workflow

Aligns code artifacts, experiment structure, and citation details so updates can be tracked and reproduced by maintainers.
